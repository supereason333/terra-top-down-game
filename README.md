# Top down shooter game

this is a prototype rougelike game made in godot, you have to survive waves of enemies.

## How it was made

The game is made with the Godot game engine. I used the urizen-onebit-tileset tileset by vurmux on Itch.io for the game (https://vurmux.itch.io/urizen-onebit-tileset). I also used royalty free music online.

## Running it

You can download the release binaries from the release or play the web version on itch.io here: https://supereason333.itch.io/top-down-shooter
